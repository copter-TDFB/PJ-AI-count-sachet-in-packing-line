สำหรับพนักงาน Packing

คู่มือการใช้งานระบบ
AI ตรวจนับซองและพิมพ์ใบปะหน้าอัตโนมัติ

ครอบคลุมการเปิดระบบ การสแกนใบ Pack การวางซองให้ AI ตรวจนับ การพิมพ์ใบปะหน้า และการแก้ปัญหาเบื้องต้น

อ่าน Checklist ก่อนเริ่มงานทุกครั้ง

สารบัญ

คำแนะนำสำหรับผู้จัดทำเอกสาร ช่องเส้นประคือพื้นที่สำหรับใส่ภาพจริง ให้เก็บไฟล์ไว้ในโฟลเดอร์ images/ ตามชื่อที่ระบุ แล้วแทนข้อความภายในช่องด้วย <img src="images/ชื่อไฟล์.png" alt="คำอธิบายภาพ"> ก่อนเผยแพร่ต้องปิดบังชื่อลูกค้า ที่อยู่ เบอร์โทร และเลข Order จริง
1. ระบบนี้ทำอะไรภาพรวม
2. Checklist ก่อนเริ่มงานตรวจเครื่องและระบบ
3. ขั้นตอนทำงานปกติสแกน นับ และพิมพ์
4. วิธีวางซองที่ถูกต้องลดการนับผิด
5. การอ่านผลตรวจนับครบ ขาด เกิน และสินค้าผิด
6. การพิมพ์ใบปะหน้าShopee, TikTok, Odoo และ Lazada
7. ข้อห้ามและข้อควรระวังสิ่งที่พนักงานห้ามทำ
8. แก้ปัญหาเบื้องต้นBridge, Script, AI, Odoo และ Printer

1. ระบบนี้ทำอะไร

ระบบประกอบด้วยโปรแกรมตรวจนับซองบนเครื่อง Windows และระบบพิมพ์ใบปะหน้าบน Browser เมื่อพนักงานสแกน Barcode ระบบจะค้นหาใบงานใน Odoo เปิดหน้าต่างกล้อง และส่งเลข Order ไปยังเว็บช่องทางที่เกี่ยวข้อง

สแกน Barcode> ค้นหา Odoo> AI ตรวจนับ> พิมพ์ใบปะหน้า

2. Checklist ก่อนเริ่มงาน

ตรวจตามรายการนี้ก่อนเริ่มกะ ห้ามข้ามรายการที่ยังไม่พร้อม

โปรแกรมและ Browser

  • เปิดโปรแกรมด้วย launcher.exe เท่านั้น
  • รอจนโปรแกรมตรวจนับเปิดและแสดงว่ากล้องพร้อม
  • เปิด Google Chrome หรือ Browser ที่ติดตั้ง Tampermonkey
  • เปิดและ Login ครบ 4 แท็บ: Shopee, TikTok, Odoo และ Lazada
  • แท็บ Odoo ต้องอยู่ที่หน้า Sales
  • ตรวจว่า Tampermonkey และสคริปต์ Auto Print เป็น Enabled
  • Refresh แต่ละแท็บ และรอข้อความ Scanner bridge connected

  • พื้นที่ภายในกรอบตรวจนับว่าง ไม่มีซองหรือวัสดุจาก Order ก่อนหน้า

4. วิธีวางซองที่ถูกต้อง

ต้องทำห้ามทำ
วางซองให้เห็นเต็มใบทุกชิ้นวางซองซ้อนหรือบังกัน
กระจายซองให้มีช่องว่างระหว่างชิ้นกองซองรวมกันเป็นชั้น
ให้ซองทุกชิ้นอยู่ในกรอบตรวจนับปล่อยส่วนใดส่วนหนึ่งของซองออกนอกกรอบ
คลี่ซองที่พับหรือยับให้เห็นรูปทรงปล่อยซองพับ ม้วน หรือกลับด้านจนระบุสินค้าไม่ได้
เอามือ อุปกรณ์ และใบ Pack ออกจากกรอบใช้มือจับซองค้างไว้ระหว่างตรวจ
รอให้ภาพและจำนวนหยุดเปลี่ยนรีบหยิบซองออกก่อนระบบแสดงผล
10
ตัวอย่างวางซองถูกต้อง
images/10-sachets-correct.jpg
ถ่ายจากกล้องจริง ให้เห็นซองเต็มใบทุกชิ้น ไม่ซ้อน มีช่องว่าง และอยู่ในกรอบทั้งหมด
11
ตัวอย่างวางซองไม่ถูกต้อง
images/11-sachets-incorrect.jpg
จัดตัวอย่างให้เห็นข้อผิดพลาดชัดเจน เช่น ซ้อน พับ บัง ออกนอกกรอบ หรือมีมืออยู่ในภาพ แล้วใส่ลูกศรสีแดงกำกับ
ห้ามปรับ Settings เอง ค่า Crop และ Confidence มีผลต่อทุก Order ของเครื่อง หากกรอบไม่ตรงหรือ AI ตรวจจับผิดปกติ ให้แจ้ง Copter เท่านั้น

5. การอ่านผลตรวจนับ

สถานะบนหน้าจอความหมายสิ่งที่ต้องทำ
ครบแล้วชนิดและจำนวนสินค้าตรงกับ Orderรอหน้าต่างปิด รับใบปะหน้า และแพ็กต่อ
ขาดAI เห็นสินค้าน้อยกว่าจำนวนใน Orderกดปิด แจ้ง Copter นับมือเทียบใบ Pack แล้วแพ็กต่อ
เกินAI เห็นสินค้ามากกว่าจำนวนใน Orderกดปิด แจ้ง Copter นับมือเทียบใบ Pack แล้วแพ็กต่อ
พบสินค้าที่ไม่ใช่ใน OrderAI ตรวจพบสินค้าคนละชนิดกับ Orderกดปิด แจ้ง Copter ตรวจชนิดสินค้ากับใบ Pack แล้วแพ็กต่อ

สิ่งที่พนักงานต้องสังเกต

  • Browser แสดงข้อความสถานะของช่องทางที่กำลังค้นหา
  • ขณะขึ้นข้อความกำลังทำงาน ให้รอจนจบ ห้ามสแกน Order ใหม่
  • ฉลากควรออกจาก Printer หลังเว็บค้นหาและเปิดเอกสารสำเร็จ
  • หากมีคำว่า Error ให้ใช้ขั้นตอนแก้ปัญหาในหัวข้อถัดไป

กรณีใบปะหน้าพิมพ์ซ้ำ

  1. หยุดก่อนติดฉลาก
  2. เทียบเลข Order บนฉลากกับงานปัจจุบัน
  3. ใช้ฉลากที่ถูกต้องเพียง 1 ใบ
  4. ขีดฆ่าหรือทำลายฉลากส่วนเกินทันที ห้ามวางค้างไว้บนโต๊ะ

เบลอชื่อ ที่อยู่ เบอร์โทร Barcode และเลข Tracking
ห้ามใช้ Ctrl+V พนักงานต้องเริ่มงานด้วยการสแกนผ่าน Desktop app เท่านั้น การใช้ Ctrl+V สามารถสั่งพิมพ์โดยข้ามขั้นตอนตรวจนับ AI

7. ข้อห้ามและข้อควรระวัง

ห้ามเหตุผล
ห้ามเปิดโปรแกรมจากไฟล์อื่นแทน launcher.exeอาจไม่ได้รับอัปเดตและใช้ไฟล์ไม่ครบ
ห้ามปิดเครื่องระหว่าง Launcher อัปเดตโปรแกรมอาจติดตั้งไม่สมบูรณ์
ห้ามปรับ Crop หรือ Confidenceทำให้ AI นับผิดทุก Order ถัดไป
ห้ามขยับกล้องกรอบตรวจนับและมุมภาพจะเปลี่ยน
ห้ามวางซองซ้อน พับ หรือออกนอกกรอบAI อาจนับขาดหรือตรวจผิดชนิด
ห้ามสแกนรัวหรือสแกนซ้ำจนกว่างานเดิมจบอาจเกิดงานซ้อนและฉลากซ้ำ
ห้ามใช้ Ctrl+V สั่งพิมพ์เป็นการข้าม flow ตรวจนับ
ห้ามเก็บใบปะหน้าซ้ำไว้บนโต๊ะเสี่ยงติดฉลากผิดกล่อง
ห้ามลบ ย้าย หรือแก้ไฟล์ในโฟลเดอร์โปรแกรมโปรแกรม โมเดล หรือระบบอัปเดตอาจเสียหาย

  2. ตรวจว่า Tampermonkey และ Auto Print script เป็น Enabled
  3. ตรวจว่าแท็บปลายทางเปิดและ Login อยู่ โดย Odoo ต้องอยู่หน้า Sales
  4. Refresh หน้าเว็บ
  5. รอข้อความ Scanner bridge connected
  6. จึงทดลองสแกนใหม่ หากยังไม่ได้ให้แจ้ง Copter

กล้องหรือโมเดล AI ไม่พร้อม

  1. ปิดโปรแกรมอื่นที่อาจใช้กล้อง เช่น Camera หรือโปรแกรมประชุม
  2. ปิด Desktop app แล้วเปิดใหม่ผ่าน launcher.exe หนึ่งครั้ง
  3. หากยังไม่พร้อม ให้แจ้ง Copter และใช้การนับมือ

  1. ตรวจว่าเครื่องเชื่อมต่ออินเทอร์เน็ต

  4. หากยังไม่ได้ ให้แจ้ง Copter และนับมือตามใบ Pack

8. แก้ปัญหาเบื้องต้น (ต่อ)

ระบบสำเร็จแต่ฉลากไม่ออก

  1. ตรวจว่า Printer เปิดอยู่และไม่มีไฟ Error
  2. ตรวจว่ามีกระดาษ ฝาปิดสนิท และไม่มีฉลากติด
  3. ตรวจสถานะเชื่อมต่อ Printer บนเครื่อง
  4. แก้ปัญหาพื้นฐานแล้วทดลองสแกนใหม่ได้เพียงหนึ่งครั้ง
  5. หากยังไม่ออก ให้หยุดสแกนและแจ้ง Copter เพื่อป้องกันงานพิมพ์ค้าง

ใบปะหน้าออกซ้ำ

  1. หยุดก่อนติดฉลาก
  2. ตรวจเลข Order บนฉลากทุกใบ
  3. ใช้เพียงหนึ่งใบ และทำลายใบที่ซ้ำ
  4. ห้ามสแกนเพิ่มจนกว่างานปัจจุบันจะเรียบร้อย

การจัดการใบปะหน้าที่พิมพ์ซ้ำ
images/26-duplicate-label.jpg
ถ่ายตัวอย่างฉลากจำลองสองใบ โดยทำเครื่องหมายว่า “ใช้ 1 ใบ” และขีดฆ่าใบซ้ำให้ชัดเจน
ใช้ฉลากทดสอบเท่านั้นและเบลอข้อมูลทั้งหมด
อาการทำทันทีถ้ายังไม่หาย
ไม่มี Scanner bridge connectedเปิด app, เปิด script, Refreshแจ้ง Copter
กล้องไม่ขึ้นปิดโปรแกรมที่ใช้กล้องและ Restart 1 ครั้งแจ้ง Copter และนับมือ
Odoo Offlineเช็ก Internet/Odoo และลอง 1 ครั้งแจ้ง Copter และนับมือ
AI นับผิดปิดหน้าต่างและแจ้ง Copterตรวจมือก่อนแพ็ก
ฉลากไม่ออกเช็ก Printer และลอง 1 ครั้งหยุดสแกนและแจ้ง Copter
หลักจำง่าย 1) ตรวจความพร้อม 2) สแกนหนึ่งครั้ง 3) วางซองให้ถูก 4) รอผล AI 5) รับฉลาก 6) แพ็กสินค้า

หากไม่แน่ใจว่าระบบทำงานถูกต้องหรือไม่ ให้หยุดการสแกน Order ใหม่และแจ้ง Copter
